非預期程式碼執行ASI05 · Unexpected Code Execution (RCE)

代理會自己寫程式、自己執行。只要一段文字被「變成」可執行的東西，攻擊者就能直接在你的主機上動手。

Vibe coding 工具和各種代理，常常即時產生程式碼並直接執行。因為這些程式碼是當下才生出來的，傳統的資安控管常常來不及檢查。提示注入、工具濫用或不安全的反序列化，都可能把「文字」變成「指令」，最後導致主機或容器被接管、被植入持久後門，甚至逃出沙箱。

    03 · 實際長什麼樣子

    一個檔名，變成三道指令

    代理有個工具：把使用者給的檔名「拼」進 wc -l {檔名} 再丟給 shell 執行。OWASP 情境 2 的例子就是：test.txt && rm -rf /important_data && echo 'done'。選一個輸入，按執行，看 shell 怎麼「讀」這串文字。

    使用者說：「幫我處理這個檔案：……」
    伺服器上的檔案
    $ 等待執行…

    範例為示意，非真實系統。修正後的做法：不經過 shell、把檔名當成「單一參數」傳入、先驗證格式、只能存取工作目錄，而且不以 root 執行。
